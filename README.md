# checkstat

Check filesystem stat paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/checkstat/

## Install / run

```bash
git clone https://github.com/theworker02/checkstat.git
cd checkstat
node src/cli.js
node --test
```
